# Code of Conduct

## Our pledge

We want SpellChecker to be a welcoming, respectful, and constructive open-source project for contributors of different backgrounds and experience levels.

## Expected behavior

Participants should:

- Be respectful and considerate.
- Give constructive technical feedback.
- Welcome questions from newer contributors.
- Focus disagreements on ideas and code rather than people.
- Respect privacy and avoid sharing another person's private information.

## Unacceptable behavior

Harassment, threats, discriminatory remarks, personal attacks, deliberate intimidation, and repeated disruptive behavior are not acceptable in project spaces.

## Scope

This Code of Conduct applies to repository discussions, issues, pull requests, reviews, and other official SpellChecker community spaces.

## Enforcement

Project maintainers may edit or remove contributions that violate these expectations and may restrict participation when necessary to keep the project constructive and safe.

For sensitive reports, use the private reporting process described in [SECURITY.md](SECURITY.md) rather than posting personal or security-sensitive details publicly.
